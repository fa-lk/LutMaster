Quick help

Images & navigation

  • Load photos: Drop image files into the workspace or click the empty area. Add more photos at any time; use the thumbnail strip to switch the active photo.
  • Compare: Press and hold the preview to temporarily show the unedited original. Use Split compare for a movable before/after divider.
  • Zoom & pan (PC): Use the mouse wheel to zoom. When zoomed in, hold the left mouse button and drag to pan the image. The cursor changes to a grab hand. Double-click to fit the image in the available preview area. On touchscreens, use a two-finger pinch to zoom and drag to pan.
  • Preview quality: STD uses an adaptive preview for faster interaction. FULL renders from the original image resolution where display size and zoom permit; it can require more processing time and memory.
  • Scopes: Enable the histogram to inspect the graded image. Clipping warnings identify values at or beyond the output limits.
  • Shortcuts: \ hold = original, W split compare, J clipping, H histogram, [/] previous/next photo, 0 fit.

Pipeline & saved Grades

  • Pipeline: Shows the active Base LUT and every loaded Cube LUT or saved Grade layer. The list order is the processing order; drag the ⋮ handle to reorder layers.
  • Enable / bypass: Use a layer checkbox to bypass it without removing it. Use the × control to remove only that layer.
  • Intensity: Set each layer from 0–100%. At 0% the layer has no visible effect; at 100% its full transform is applied. Intermediate values blend the layer output with its input.
  • Base LUT: This is a separate upstream input transform. It is applied before the layers in the Pipeline and can be bypassed or removed independently.
  • Save Grade: Saves the current editor adjustments internally as a reusable Grade. It does not create a .cube file. Select a saved Grade under My LUTs to add it as a reversible layer in the Pipeline.
  • Cube LUT: Import a .cube file to add an external transform as a layer. Cube LUTs and saved Grades can be mixed in the same stack.
  • Undo: Layer additions, removals, intensity changes and reordering are part of the edit history. Reset all clears the current edit state.

Adjustments & curves

  • Sections: Use each section's checkbox to bypass that adjustment family while retaining its settings. The reset button resets that section; Reset all clears the complete edit.
  • Sliders: Drag for continuous adjustment or enter a numeric value. Double-click a slider or setting to restore its default.
  • Tone curve: Select RGB or an individual channel. Click to add a control point, drag to move it, and double-click a point to remove it. Curve endpoints are fixed.
  • Hue curves: Drag the handles to change hue or saturation within the corresponding hue/luminance range.
  • Colour pickers: Activate the white-balance or secondary-colour picker, then click a suitable neutral or target area in the photo.
  • Automated corrections: Auto Grade estimates global tonal settings. Auto Grade – Subject lets you outline a subject before applying a localised tonal optimisation. Other automated controls estimate individual corrections from the active photo.
  • A/B slots: Store two adjustment states for comparison. Copy transfers the current slot's settings to the other slot.

Export & project files

  • Save photo: Exports the active photo with the current pipeline and adjustments. Choose JPG quality or lossless PNG in the export dialog.
  • Save all photos: Applies the same current edit to every loaded photo and exports them as a batch.
  • Export LUT: Generates a .cube transform from the current grade. Choose the LUT size; larger cubes preserve finer interpolation but increase file size.
  • Export look pack: Exports saved looks as .cube files. This is separate from saving a Grade internally.
  • Save / load project: Stores or restores the editing state and layer stack. The project file stores the current editing state and pipeline configuration.
  • Local processing: Image editing and saved looks are handled in this browser; photos are not uploaded by the app.
